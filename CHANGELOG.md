# Changelog

## 1.0.0

- Phrase detection with look-ahead (0.5 s, 1 s, 2 s) and a latency-free Live mode.
- Delay with free or tempo-synced time, feedback, mix, and a Between control for the signal outside the throws.
- Flat hairline interface: values as bars, monospace labels, phrase-end meter.
- Units and decimals come from the parameters themselves, so the plugin and the host read the same.
- VST3, CLAP, LV2 and a standalone app on Windows; AU and VST3 on macOS.
- Windows installer with an HTML manual, built with Inno Setup.
